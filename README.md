# RedSea-Mangroves

This repository contains the scripts used for the metagenomic analyses presented in:

Digging into leaf and root microbiomes of gray mangrove trees

## Repository structure

- `scripts/` – Analysis scripts used throughout the study (Colaborators: Lucas Mendes, Tahira Jamil and Maria F Peña-Valencia).
- `metagenomic-pipeline/` – scripts for the MAGs recovery (Colaborator: Tahira Jamil).
- `docs/` – Additional documentation.

## Notes

This repository contains analysis code only. Large datasets, intermediate files, and sequencing data are not included.
